      O sistemu

      Opis sistema

      Ekspertski sistem pruža podršku policijskim službenicima tokom saobraćajne kontrole vozača pod dejstvom alkohola i psihoaktivnih supstanci. Sistem ne donosi pravne odluke, već policijskom službeniku daje preporuke i objašnjenja na osnovu unesenih podataka.

      Korišćene tehnologije

      • Drools 7.74 — engine za pravila, CEP, sabloni
      • Forward chaining — 4 nivoa pravila
      • Backward chaining — rekurzivni query-ji
      • CEP + pseudo sat — klizni vremenski prozori
      • Accumulate — brojanje prekršaja i događaja
      • Rule Templates (.drt) — 5 kategorija sablona
      • Spring Boot 3.5 — REST API
